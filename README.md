# mercedes-cloud

Исследовательский проект независимой телематики для Mercedes-Benz GLB 200d 4MATIC (X247, 2020).

## Цель

Безопасно исследовать доступные данные через Vgate iCar Pro BLE, затем построить собственный телематический backend. Штатный HERMES/TCU и eCall не изменяем.

## Первый этап: read-only OBD-II probe

Требуется macOS с Bluetooth, Python 3.10+ и Vgate iCar Pro BLE.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python probe/vgate_ble.py
```

Включите зажигание, поставьте автомобиль на стоянку. Адаптер должен быть вставлен в OBD-II. Программа ищет BLE-устройство, показывает кандидатов, запрашивает подтверждение и последовательно отправляет безопасные диагностические команды. Сырые ответы записываются в `captures/` (игнорируется Git).

**Внимание:** в захватах могут быть VIN и другие идентификаторы автомобиля. Не публикуйте их без редактирования. Не используйте сканер во время движения.

## Структура

- `probe/` — BLE-подключение и первичная диагностика;
- `docs/` — гипотезы, протоколы и результаты исследований;
- `captures/` — локальные диагностические логи (не коммитить);
- `backend/` — будущий Go backend.

## Ограничения

Стандартный OBD-II не гарантирует доступ к HERMES (N112/9). Утилита не выполняет UDS SecurityAccess, запись, сброс ошибок, управление исполнительными механизмами или обход защиты. Для идентификации TCU может потребоваться XENTRY или совместимый диагностический прибор.
