# План исследования GLB X247

## M0 — BLE / OBD-II

1. Установить связь с Vgate iCar Pro BLE.
2. Зафиксировать версию адаптера и определённый ELM-протокол.
3. Считать маски поддерживаемых PID, VIN (локально), ECU name (если поддерживается).
4. Проверить стабильность повторных сессий и таймаутов.

**Критерий:** локальный JSON с raw responses и отметками времени.

## M1 — карта телеметрии

Только стандартные read-only PID. Выяснить доступность топлива, оборотов, температуры, скорости, напряжения и дизельных параметров. Отделять неподдерживаемые PID от ошибок транспорта.

## M2 — HERMES

Установить аппаратный номер и версию N112/9 через профильный диагностический инструмент или документацию по конкретному VIN. Исследовать публичные сервисные материалы и архитектуру, не изменяя eCall, SIM, сертификаты или прошивку.

## M3 — собственное облако

Go ingestion API, аутентификация устройства, текущее состояние, история поездок и web UI. Вначале симулятор, затем read-only агент. Удалённые управляющие команды — отдельный проект после анализа безопасности.
